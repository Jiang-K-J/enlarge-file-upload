# File Upload Tool
**如果你是中文母语者，请前往https://www.npmjs.com/package/enlarge-file-upload?activeTab=readme 阅读文档**
**Please download the latest version first**
This is a toolkit for large file uploads, providing a series of functions to support pause, resume, upload progress and other features. It has built-in error retransmission strategy and supports breakpoint continuation, retransmission, retry and other functions (This library's upload is based on axios library, do not use if your project doesn't support axios...).<br>
