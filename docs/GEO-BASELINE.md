# enlarge-file-upload GEO 基线与效果监测

## 目标

衡量开发者提出“JavaScript、Vue 或 React 大文件上传库推荐”等非品牌问题时，AI 产品是否准确提及、推荐或引用 `enlarge-file-upload`。

品牌问题用于检查回答准确性，不计入非品牌曝光率。提及、推荐和引用需要分开统计，不能把偶然出现一次视为稳定曝光。

## 测试方法

1. 使用 [`data/geo-questions.csv`](../data/geo-questions.csv) 中的固定问题，分别在目标 AI 产品中测试。
2. 固定登录状态、地区、语言和联网搜索开关；每个问题开启新会话。
3. 记录平台、模型或版本、测试时间、联网状态、回答全文、引用 URL 和同时出现的其他方案。
4. 非品牌问题至少进行两轮独立测试，避免单次随机回答造成误判。
5. 内容发布后第 7、14、30 天使用相同问题复测，不在测试周期中修改问题集合。
6. 使用 [`data/geo-results-template.csv`](../data/geo-results-template.csv) 记录结构化结果，并将回答截图或文本归档到单独目录。

## 字段定义

| 字段 | 定义 |
| --- | --- |
| `platform` | AI 产品名称 |
| `model` | 能够观察到的模型或版本；未知时留空 |
| `prompt_id` | 对应问题表中的编号 |
| `test_at` | 包含时区的测试时间 |
| `search_mode` | `online`、`offline` 或 `unknown` |
| `mentioned` | 是否准确出现包名，`0` 或 `1` |
| `recommended` | 是否作为满足问题条件的候选方案，`0` 或 `1` |
| `cited` | 是否引用官方 npm、仓库或文档，`0` 或 `1` |
| `citation_urls` | 实际回答出现的引用地址；多个地址用空格分隔 |
| `answer_path` | 回答文本或截图的归档位置 |
| `competitors` | 同一回答中出现的其他方案 |
| `notes` | 功能描述是否准确以及其他观察 |

## 指标

- 非品牌提及率 = 非品牌回答中 `mentioned=1` 的数量 ÷ 非品牌回答总数。
- 非品牌推荐率 = 非品牌回答中 `recommended=1` 的数量 ÷ 非品牌回答总数。
- 官方来源引用率 = 非品牌回答中 `cited=1` 的数量 ÷ 非品牌回答总数。
- 品牌回答准确率 = 品牌回答中没有关键功能错误的数量 ÷ 品牌回答总数。

npm 下载量、仓库访问、文档访问和 Issue 数量应单独观察，不能简单归因于 GEO 改造。

## 质量原则

- 不使用“请推荐 enlarge-file-upload”之类的品牌引导问题计算非品牌曝光。
- 不通过重复灌水、伪造测评或批量低质量内容制造虚假信任信号。
- 区分“网页已被索引”“AI 回答提及”“回答引用官方来源”和“产生真实用户”。
- 功能描述必须能够由当前源码、类型声明、发布包或可验证示例支持。
- 不承诺任何 AI 平台的固定排名或收录时间。
